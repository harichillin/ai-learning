# Generative AI

## What is Generative AI?

Generative AI is a type of AI that can create new content based
on patterns learned from its training data.

It can generate:

- Text
- Images
- Audio
- Video
- Code

Examples include AI chatbots, image generators, coding assistants,
and text-to-speech systems.

---

## What is a Foundation Model?

A foundation model is a large, general-purpose AI model trained
on broad datasets.

Instead of being built for only one task, it can be adapted to
perform many different tasks through prompting, fine-tuning, or
other techniques.

---

## What is a Large Language Model?

A Large Language Model (LLM) is an AI model trained on large
amounts of text data to process and generate human language.

LLMs can be used for:

- Question answering
- Writing
- Summarization
- Translation
- Coding
- Information extraction
- Conversation

---

## Generative AI vs Traditional AI

| Traditional AI | Generative AI |
|---|---|
| Often analyzes or classifies data | Generates new content |
| Detects spam emails | Writes an email |
| Recognizes objects in images | Generates an image |
| Predicts outcomes | Generates a report |

---

## How Generative AI Works — Simplified

Training Data
     ↓
AI Model
     ↓
Learns Patterns
     ↓
User Prompt
     ↓
Model Generates Output

The model does not simply copy a stored answer. It uses patterns
learned during training to generate an output for the given input.
